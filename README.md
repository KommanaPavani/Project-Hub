# ProjectHub 🚀

ProjectHub is a web-based platform to find, share, and manage academic and technical projects. Whether you're working on Artificial Intelligence, Web Development, Cyber Security, or any other domain, this platform allows users to browse existing projects, upload their own, and collaborate within a shared tech community.

## Live Demo
Currently runs on `localhost` using XAMPP.

##  Description

ProjectHub is an online place to find, share, and manage projects. If you're interested in AI, ML, or any other area, you can easily browse projects by category and add your own project summaries.
ProjectHub is easy to use and helps build a lively community where people share ideas and knowledge. Join in to connect with others and bring your ideas to life together.

---

## 🔐 Signup Requirements

To create an account on ProjectHub, users must provide the following details:

- Full Name
- Email Address
- Mobile Number

These fields are mandatory for successful registration and are used to associate users with their project submissions and for contact purposes.

---

## 🔑 Features

- 🌍 Domain-wise project categorization
- 📝 Project submission with title, description, tools used, and contact
- 🔍 Easy project browsing based on interest
- 👤 User signup/login system with required details
- 🧑 User account interface
- 🛠 Admin/project manager dashboard (if applicable)

---

## 🛠 Tech Stack

- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Backend**: PHP
- **Database**: MySQL
- **Local Server**: XAMPP

---

## 💡 How to Run the Project

1. Clone or download this repository
2. Install and run **XAMPP**
3. Move the project folder into `htdocs`
4. Start **Apache** and **MySQL**
5. Import the database (SQL file if available) into **phpMyAdmin**
6. Visit `localhost/ProjectHub` in your browser
